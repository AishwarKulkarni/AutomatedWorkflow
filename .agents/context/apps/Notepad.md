# Notepad Automation Guide

## Keyboard Shortcuts
| Task | Shortcut | Notes |
|---|---|---|
| New File | `^n` | |
| Save | `^s` | Opens save dialog if unsaved |
| Save As | `^+s` | Opens save as dialog |
| Select All | `^a` | |
| Find | `^f` | Opens find dialog |
| Replace | `^h` | Opens replace dialog |

## Common Workflows
- **Save As:** Press `^+s` to open the Save As dialog, wait for the window to appear, then type the filename and press `{Enter}`.

## UI Quirks / Gotchas
- Standard Windows shortcuts usually work fine.
- When opening dialogs like Find or Save, be sure to wait for the new window to gain focus before typing.
