# Search or Open a Website in Brave

Use this workflow when the user asks to search the web or open a specific website in Brave. Use only the search terms or web address supplied or clearly requested by the user.

## 1. Focus Brave
Bring Brave Browser to the foreground, launching it if it is not already open.

## 2. Enter the Search or Website Address
Press Ctrl+L to focus Brave's address bar. Enter the website address requested by the user, or enter the user's search query. Use the clipboard and paste for long text.

## 3. Navigate
Press Enter to open the address or run the search.

Do not submit forms, sign in, purchase items, download files, or change account or website settings as part of this navigation workflow. Those tasks require a separate matching workflow.
