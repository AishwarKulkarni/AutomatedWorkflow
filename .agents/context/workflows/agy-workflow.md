# Antigravity Workflow Execution

This workflow executes when the user types `/agy-workflow` along with a prompt or task.

## Focus Antigravity IDE

Focus the Antigravity IDE application and ensure the agent chat is visible and ready for input.

## Send Instructions to Agent

1. Enhance the user's provided prompt with relevant details and specify the appropriate skill or slash command.
2. Type the enhanced instruction into the agent chat. The format should be:
   `/slash-command or skill name (user given prompt but enhanced)`

   Example: `/grilling Please stress-test the following plan: [enhanced details]`

3. Press `{Enter}` to send the message to the agent.
